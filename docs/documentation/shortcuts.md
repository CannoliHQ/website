# Shortcuts

Shortcuts bind a button combo to an in-game action, so you can trigger it instantly without opening the [In-Game Menu](playing-games.md#opening-the-in-game-menu).

## Assigning a shortcut

While playing, open the In-Game Menu and go to **Settings → Shortcuts**. Highlight an action, then press the button combo you want to bind to it.

## Available actions

| Action | What it does |
|--------|--------------|
| **Save State** | Saves the game to the current slot. |
| **Load State** | Loads the current slot. |
| **Reset Game** | Resets the game to its initial state. |
| **Save and Quit** | Writes a save state, then exits to the launcher. |
| **Save and Quit (Hold)** | The same, but only when the combo is held down, so it is not triggered by accident. |
| **Cycle Scaling** | Steps through the screen scaling modes. |
| **Cycle Shader** | Steps through the available shaders. |
| **Toggle FPS Display** | Shows or hides the on-screen FPS counter. |
| **Toggle Fast Forward** | Turns fast forward on or off. |
| **Hold Fast Forward** | Fast forwards for as long as the combo is held. |
| **Open Guide** | Opens the game's [Guide](playing-games.md#guide). |
| **Open In-Game Menu** | Opens the [In-Game Menu](playing-games.md#opening-the-in-game-menu). |
